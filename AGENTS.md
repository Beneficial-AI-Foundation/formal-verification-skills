# Repository Instructions

## Commit messages

All commits, including GSD implementation and artifact commits, must use a descriptive
Conventional Commit subject: `type(scope): subject`.

- Name the feature, bug, or area in the type/scope and describe the behavior in the subject.
- Never use dates, GSD phase or plan IDs, quick-task IDs, task numbers, or similar workflow
  bookkeeping as the subject slug or scope.
- Put issue references in the commit body or footer when useful.
